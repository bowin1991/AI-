## 1. 文档目标与范围

本文将合伙人端 PRD 转换为前端页面级需求，供产品、设计、前端和测试共同评审。本文不定义服务端数据模型、分佣计算实现或运营后台页面；前端依赖的状态和数据以原 PRD 及配套后台接口为准。

合伙人端本期页面包括：申请入驻、手机号验证码登录、申请状态查询、合伙人工作台首页、推广中心、我的客户、佣金积分中心。审核中和已拒绝的申请人只能访问申请状态页面；审核通过且账号正常后才能访问工作台。

本文按“积分保留两位小数”的业务口径描述前端展示。积分计算与取整由服务端完成（四舍五入到分），前端按两位小数原样展示，不自行换算或二次取整。

## 2. 页面清单

| 页面 | 路径建议 | 可访问用户 | 核心目的 |

| 工作台首页 | `/partner` | 已通过且账号正常的合伙人 | 查看核心数据并进入业务模块 |

## 3. 全局结构与导航

### 3.1 未获批状态

- 申请入驻和登录页使用独立门户布局，不展示工作台导航。
- 审核中、已拒绝用户登录后只显示申请状态或审核结果，不显示推广、客户、积分等工作台入口。
- 已拒绝状态不提供修改资料或再次申请入口。运营侧修改申请资料或将状态调整为已通过后，申请人刷新状态或重新登录，系统按最新状态分流。

### 3.2 已获批工作台

- PC 端提供工作台导航，入口为“首页、推广中心、我的客户、佣金积分”。
- 移动端优先使用底部主导航，四个入口保持固定顺序；当前页面入口明确高亮。
- 进入页面时校验登录状态及合伙人账号状态。会话失效时返回登录页；账号冻结或清退时提示合作权限暂停，不渲染工作台数据。
- 页面切换后保留可恢复的列表筛选和排序状态；退出登录后清除本地敏感会话数据。

### 3.3 通用反馈

- 短时操作反馈使用轻提示，例如复制成功、复制失败、推荐码无效。
- 影响表单提交、登录或结算记录加载的错误在页面内显示，并提供明确的重试或返回操作。
- 请求中禁用对应提交按钮，避免重复提交；列表加载更多时只锁定列表请求，不阻断页面其他操作。
- 页面切换或刷新不能短暂展示未经状态校验的工作台内容。

## 4. 页面需求

### 4.1 申请入驻页

**目标与结构**

1. 招募视觉区：立理 S1 合伙人招募 Banner 和合作权益说明。
2. 申请表单区：真实姓名、所属单位、身份属性、手机号、短信验证码、微信号。
3. 提交区：申请须知、提交按钮及登录入口。

**交互规则**

- 真实姓名：必填，2–20 个字符，支持中英文。
- 所属单位：必填，2–50 个字符。
- 身份属性：必填，2–30 个字符。
- 手机号：必填，校验大陆 11 位有效手机号。
- 短信验证码：6 位数字；发送成功后 60 秒内不可重发，同一手机号每日最多发送 10 次，并按安全策略触发图形验证。
- 微信号：选填，6–30 个字符，仅允许数字、字母、下划线和减号。
- 提交前校验必填字段与格式；校验错误定位到字段，保留已填内容。
- 提交时由服务端按手机号检查申请记录。若已存在，不创建新申请，提示“该手机号已有申请记录，请登录查看状态”。
- 提交成功后显示成功结果和【前往登录页】操作。

**加载、空和错误状态**

- 页面初始化：表单字段可直接使用；Banner 加载失败时显示品牌色占位，不阻断申请。
- 发送验证码中：按钮显示发送中并禁用；成功后进入 60 秒倒计时；失败后恢复按钮并显示可理解的错误原因。
- 提交中：按钮显示提交中并禁用，防止重复创建；成功后切换至提交成功状态。
- 重复申请：保留当前输入并提示登录查看现有申请；不清空表单后再让用户重复操作。
- 网络失败：保留已填写内容，显示【重试提交】；提交结果不确定时先查询手机号对应申请状态，避免重复创建。

### 4.2 登录页

**目标与结构**

1. 门户品牌区。
2. 手机号输入框。
3. 短信验证码输入框及【获取验证码】按钮。
4. 【登录系统】按钮。
5. 【申请成为立理合伙人】入口。

**交互规则**

- 手机号格式错误时不发送验证码；验证码只能输入 6 位数字。
- 验证码发送遵循申请页相同的 60 秒倒计时、每日次数限制及安全验证要求。
- 登录成功后服务端返回申请/账号状态，前端按状态跳转：审核中或已拒绝进入申请状态页；审核通过且账号正常进入工作台。
- 手机号没有申请记录时提示“该手机号尚未申请成为立理合伙人，请先提交申请”，并提供【立即申请】快捷入口，手机号带入申请表单。
- 已冻结或已清退的合伙人不进入工作台，展示合作权限暂停提示及官方联系指引。
- 若本地保留上次登录手机号，可作为便捷输入；界面不得把脱敏号码当作可提交的完整号码，用户应能修改。

**加载、空和错误状态**

- 验证码发送中、倒计时、发送失败均在验证码按钮附近反馈。
- 登录提交中禁用登录按钮；登录失败保留手机号，不清空验证码前先提示具体原因。
- 短信验证码错误、过期、频次受限、网络异常分别显示对应提示。
- 登录响应状态未知时提供重试；重新请求前不得假定用户为已通过状态。

### 4.3 申请状态页

**审核中状态结构**

1. 状态标识：“审核中”。
2. 申请信息：姓名、所属单位、身份属性、提交时间。
3. 审核说明：展示当前审核进度和预计时长（时长文案待统一，见第 7 节）。
4. 操作区：【刷新状态】、【退出登录】。

**已拒绝状态结构**

1. 状态标识：“已拒绝”。
2. 拒绝原因：展示运营后台填写的原因。
3. 申请信息摘要：姓名、所属单位、提交时间。
4. 操作区：【刷新状态】、【退出登录】；不显示修改资料或再次申请入口。

**交互及状态变化**

- 页面进入时自动获取最新状态；点击【刷新状态】重新请求状态。
- 刷新期间状态内容保留，操作按钮显示加载反馈。
- 如果运营已将 `REJECTED` 调整为 `APPROVED`，刷新成功后提示状态已更新并进入工作台。
- 状态查询失败时保留最后一次有效状态，并显示【重试】；不得把失败解释成审核拒绝。
- 申请状态页无业务数据空状态；缺少拒绝原因时显示“请联系官方运营人员了解详情”，不出现空白区域。

### 4.4 工作台首页

**模块结构**

1. 页面标题区：合伙人门户标识、合伙人称呼及账号状态。
2. 业务数据概览：累计点击量（UV）、累计绑定客户、付费会员用户、可结算积分及冻结积分。
3. 快捷入口：推广中心、我的客户、佣金积分。
4. 数据更新时间或加载失败说明。

**交互规则**

- 点击概览指标跳转对应模块；点击快捷入口进入相应页面。
- 积分统一保留两位小数并带千位分隔；页面不显示积分兑人民币金额。
- 首次加载期间指标区显示固定尺寸骨架屏，避免布局跳动。
- 部分接口失败时，仅对应指标显示错误占位和重试入口，其他模块保持可用。

**空状态**

- 新合伙人尚无点击或客户时显示 0 值，并提供【前往推广中心】入口。
- 尚无积分流水时显示“暂无分润记录”，不影响其他首页数据展示。

### 4.5 推广中心

**模块结构**

1. 专属推广链接：链接内容、【复制专属链接】。
2. 专属推荐码：4 位纯数字推荐码、【复制推荐码】。
3. 推广海报：海报预览、二维码、推荐码明文及保存/下载操作。

**交互规则**

- 点击复制后写入剪贴板并提示成功；浏览器不支持或用户拒绝剪贴板权限时，提供可选中的文本及手动复制提示。
- 推荐码和推广链接来自已获批合伙人资料，不由前端生成或修改。
- 海报生成完成后支持预览；二维码扫描结果应与专属推广链接一致。
- H5 显示长按保存提示，并提供【下载海报图片】。不支持原生保存时打开高清图片，提示用户长按或截屏。
- PC 提供【下载高清海报】并触发本地 PNG/JPG 下载。

**加载、空和错误状态**

- 首屏加载时链接、推荐码和海报区域分别显示骨架屏。
- 已获批账号缺少链接或推荐码属于异常状态，不展示“暂无数据”作为正常空状态；提示刷新或联系运营。
- 海报渲染中显示加载状态；超过预期时间仍未完成时提供重试。
- 二维码、字体或图片资源加载失败时显示错误占位和【重新生成】操作，不允许下载不完整海报。
- 下载失败时保留海报预览，并提示使用长按/新窗口保存方式。

### 4.6 我的客户

**模块结构**

1. 概览指标：累计点击量（UV）、累计绑定客户、付费会员用户。
2. 筛选区：会员状态筛选。
3. 排序区：会员到期时间、注册时间、添加/绑定时间；各排序字段支持升序和降序。
4. 客户列表：客户标识、添加/绑定时间、注册时间、当前会员状态、会员到期时间。
5. 分页/加载更多区：默认每页 20 条，移动端触底加载。

**交互规则**

- 客户手机号始终脱敏展示；没有可用昵称时使用脱敏手机号作为标识。
- 状态筛选至少包含全部、未开通、月卡生效中、年卡生效中、会员已过期。
- 更改筛选或排序后从第一页重新加载；切换排序方向时更新箭头和结果顺序。
- 点按排序字段切换升/降序；移动端筛选项可放入底部弹层，点击【应用】后刷新列表。
- 列表每次请求分页数据；加载更多期间锁定列表加载操作，避免重复请求。
- “会员到期时间默认降序”沿用原 PRD 当前描述，但与“优先跟进即将到期客户”的目标存在冲突，默认方向需在评审后定版。

**加载、空和错误状态**

- 首次加载：概览卡片和列表分别显示骨架屏；列表骨架与最终行高一致。
- 无绑定客户：显示空状态“暂无客户”，提供【前往推广中心】入口。
- 筛选后无结果：显示“没有符合条件的客户”，提供【清除筛选】。
- 加载更多：列表底部显示加载指示；无更多数据时显示“已加载全部”。
- 首屏或分页请求失败：保留已有列表；首屏失败提供【重试】，分页失败提供【重新加载】。

### 4.7 佣金积分中心

采用单页分区或页内标签切换，包含“积分概览、分润流水、线下核销记录”三个区域。移动端优先使用页内标签，不要求横向浏览宽表格。

**积分概览模块**

- 指标：当前获得总积分、冻结积分、月末可解冻积分、可结算积分。
- 积分保留两位小数（四舍五入到分）；月末可解冻积分以预计值样式展示，不与冻结/可结算余额混为可用余额。
- 首次加载显示骨架屏；接口失败时单独显示重试，不将未知余额显示为 0。
- 所有指标为 0 时正常显示 0，并在流水区展示空状态。

**分润流水模块**

- 字段：记账时间、脱敏订单号、购买商品、实付金额、分成比例、产生积分、分润状态、预计解冻时间。
- 状态包括冻结中、已解冻、退款作废。
- 积分保留两位小数展示，前端直接显示服务端结果；不展示“1 积分 = 1 元”等换算文案。
- 首屏显示骨架行；无流水时显示“暂无分润记录”；加载失败时提供重试。
- 移动端每条流水显示为纵向摘要，订单号和日期可换行，不使用横向滚动表格。

**线下核销记录模块**

- 字段：结算批次号、本次核销积分、核准时间、结算状态、打款凭证说明/备注。
- 无记录时显示“暂无核销记录”。
- 加载时显示骨架行；失败时保留其他标签数据并允许单独重试。
- 该模块为只读，不向合伙人提供发起提现或修改核销记录的入口。

## 5. 主要页面状态矩阵

| 页面/状态 | 加载中 | 空状态 | 错误/异常 |
| :--- | :--- | :--- | :--- |
| 申请入驻 | 验证码发送、申请提交按钮状态 | 不适用 | 字段校验、重复申请、短信失败、网络错误 |
| 登录 | 验证码发送、登录提交 | 不适用 | 无申请记录、验证码错误/过期、账号冻结/清退 |
| 申请状态 | 状态卡片刷新 | 不适用 | 查询失败保留上次状态并重试 |
| 工作台首页 | 概览骨架屏 | 数值显示 0 | 指标级错误占位和重试 |
| 推广中心 | 链接/推荐码/海报分区加载 | 获批账号不应缺少物料 | 缺少配置、渲染失败、剪贴板或下载失败 |
| 我的客户 | 列表骨架、分页加载 | 无客户与筛选无结果分开处理 | 首屏/分页失败分别重试 |
| 佣金积分 | 概览/流水/核销记录分区加载 | 余额为 0、无流水、无核销记录 | 分区级错误，不以 0 代替未知值 |

## 6. 移动端与响应式要求

- 以 375–430px 宽度移动端竖屏为优先设计范围；兼容主流 iOS/Android 浏览器及 PC Web。
- 交互控件可点击区域不小于 44px；底部固定导航和操作按钮需避开系统安全区。
- 表单单列布局；键盘弹出时验证码按钮和提交按钮仍可访问，表单错误提示不遮挡输入框。
- 工作台移动端使用底部导航；申请、登录和申请状态页不显示工作台导航。
- 客户和账务列表使用卡片/纵向摘要布局，避免主要信息依赖横向滚动；长订单号、手机号和单位名称可断行。
- 筛选、排序等次级操作可用底部抽屉；点击应用后关闭抽屉并刷新结果。
- 长列表默认每页 20 条，滚动到底部加载下一页；加载状态固定在列表末尾，不改变已有项目尺寸。
- 海报预览宽度适配视口并保持原始比例；下载图片使用适合分享的清晰度，页面缩放不影响二维码扫描。
- PC 端表单/状态页面居中展示；工作台列表在空间不足时自适应换行或切换摘要卡片，不裁切核心字段。

## 7. 待确认事项

1. **审核时限文案不一致**：申请成功提示写“3–5 个工作日”，审核状态页写“1–2 个工作日”。确认统一时限；确认前前端使用不承诺具体天数的审核中说明。
2. **客户到期排序方向**：原 PRD 指定默认降序，但需求目标是优先找到即将到期客户。建议评审是否改为按最近到期日升序，并明确已过期、未开通客户的位置。
3. **积分取整规则（已确认）**：积分 = 实付金额 × 分成比例，四舍五入保留两位小数（精确到分），前端统一按两位小数展示；原 PRD 流水示例已同步更新为 `110.70`。
4. **推广首页指标布局**：原 PRD 定义了客户概览和积分指标，但没有指定工作台首页是否重复展示这些指标。本文首页概览为页面组织建议，需产品确认首页最终保留的指标。
5. **账号冻结/清退说明**：确认前端联系官方运营的展示方式与联系方式配置来源。

## 8. 验收要点

- 同一手机号重复提交时，服务端拒绝创建第二条申请，前端提示登录查看已有状态。
- `PENDING` 和 `REJECTED` 用户只能看到申请状态页；`REJECTED` 用户无再次申请或自行修改入口。
- 运营将 `REJECTED` 调整为 `APPROVED` 后，申请人刷新状态或重新登录可进入工作台。
- 账号冻结或清退时不能加载工作台业务数据。
- 推荐链接、推荐码复制成功/失败，海报生成/下载失败均有明确反馈和可行的后续操作。
- 客户列表筛选、排序、分页和空结果状态可用；手机号脱敏。
- 积分以两位小数展示；余额接口失败时不显示为 0；空流水、空核销记录和加载失败状态彼此区分。
- 375px 宽度下主要页面无横向溢出，关键操作可触达，软键盘不遮挡当前输入和提交操作。
