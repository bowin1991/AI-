# PRD 与合伙人端 Demo 同步更新计划

## 一、目标与范围

将 `Demo/立理 S1 合伙人端 Demo.html` 当前已实现的内容（含本次及此前在 Demo 中删除、改名、调整的项）同步回 `docs/立理S1合伙人端系统需求规格说明书(PRD).md`，使 PRD 成为可直接交付开发的现行口径。

- 只改 PRD 文档，不改 Demo 代码。
- 以 Demo 现状为准（已与用户确认：结算批次号按 Demo 保留；Demo 中新增但 PRD 未描述的交互全部补充进 PRD）。
- 不改动 PRD 中与 Demo 一致的部分（登录/忘记密码流程、订单取整规则、积分合规隔离原则、标签管理机制、备注编辑机制等）。
